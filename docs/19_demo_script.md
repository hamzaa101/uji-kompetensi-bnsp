# Demo Script 10-15 Menit

1. Login admin `admin@klinik.test`.
2. Tunjukkan dashboard: statistik, chart, notifikasi, monitoring.
3. Buka data obat, search/filter, tambah atau edit obat, upload gambar.
4. Buka batch stok, tunjukkan expiry date dan jelaskan FIFO.
5. Buka laporan, pilih periode, export PDF.
6. Buka import CSV, upload sample, jelaskan `php artisan queue:work`.
7. Buka simulasi, generate low stock alert dan application error.
8. Login pasien `pasien@klinik.test`.
9. Search obat, lihat detail, tambah obat bebas ke cart, checkout.
10. Tambah obat resep, checkout dengan upload resep, status waiting prescription.
11. Login apoteker, buka verifikasi resep, approve, jelaskan stok dikurangi FIFO.
12. Login kasir, buat transaksi offline, preview struk.
13. Kembali admin, tunjukkan audit log dan error log.
14. Tunjukkan dokumen cutover, rollback, impact analysis, debugging, dan UAT.
