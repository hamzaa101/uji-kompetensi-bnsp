# User Guide

## Admin

Login, buka dashboard, kelola kategori/supplier/obat/batch, lihat laporan, import CSV, monitoring, error log, audit log, dan simulasi alert.

## Apoteker

Buka verifikasi resep, lihat preview gambar resep, approve atau reject dengan catatan. Buka stok alert untuk daftar stok kritis dan obat hampir expired.

## Kasir

Buka transaksi baru, pilih obat dan quantity, pilih cash/transfer/ewallet/insurance, checkout, lalu print struk.

## Pasien

Register/login, buka katalog, search/filter obat, lihat detail, tambah ke cart, checkout, upload resep jika diperlukan, dan pantau riwayat pesanan.

## Pembelian Online

Pilih obat, tambah ke cart, cek quantity, pilih metode pembayaran, upload resep bila ada obat resep, lalu buat order.

## Verifikasi Resep

Apoteker membuka order pending, memeriksa gambar resep, approve untuk memproses dan mengurangi stok FIFO atau reject untuk memberi notifikasi pasien.

## Laporan

Admin memilih periode laporan, membaca rekap harian/bulanan/top medicine/status/stok kritis, lalu export PDF.
